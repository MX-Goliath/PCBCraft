# Архитектура

`eda-app → eda-render / eda-io / eda-core → eda-geom`

- `eda-geom`: координаты документа в целых нанометрах.
- `eda-core`: Document, Pad, Track, Layer, Units, валидация, история.
- `eda-io`: собственный JSON v1, ограничение размера, проверка данных,
  запись через временный файл в том же каталоге и atomic persist.
- `eda-render`: camera, read-only canvas, hit testing и view state.
- `eda-app`: eframe/wgpu, оболочка, общие обработчики команд для
  меню/toolbar/shortcut, диалоги, Properties, настройки.

Ядро не зависит от egui, Win32 или Altium. UI отправляет изменения через
History::commit. Пока история хранит снимки малых документов; далее заменить
на типизированные изменения, сохраняя семантику атомарности и ревизий.

eframe 0.32.3 и egui 0.32.3 зафиксированы совместно. Используется один
цикл событий и wgpu backend eframe; отдельный GPU device не создаётся.
Canvas пока использует egui Painter, следующий этап добавит собственные
пакеты отрисовки через тот же backend. egui_dock будет подключён при
реализации docking; текущие панели поддерживают resize/hide.

Вкладки хранят независимые камеры, выделение и историю. Сохранённый снимок
определяет dirty state, поэтому undo к сохранённому содержимому снимает `*`.
Настройки и геометрия панелей сохраняются eframe; документы и несохранённая
сессия пока не восстанавливаются автоматически.

Никакие электрические свойства, связность, DRC, трассировка, импорт Altium
или schematic compiler текущим примером не моделируются. Pads/Tracks
в примере — собственные геометрические примитивы без nets/footprints.

Linux и Windows — равноправные целевые платформы. Пути хранятся в PathBuf,
файловый слой использует стандартный Rust API и tempfile; платформенные
диалоги предоставляет rfd. X11/Wayland включены явно. Настройка локального
GNU linker на Windows ограничена scripts/dev.ps1 и игнорируемым .tools.
Проверки Linux и Windows заданы в .github/workflows/check.yml; визуальный
запуск на каждой ОС требует отдельной проверки.

Первоисточники API: [eframe 0.32.3](https://docs.rs/eframe/0.32.3/eframe/),
[egui_dock 0.17.0](https://docs.rs/egui_dock/0.17.0/egui_dock/).

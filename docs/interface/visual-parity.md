# Визуальное соответствие Altium Designer

Обязательная цель: точная копия доступного Altium Designer Enterprise 24.4.1,
Windows и Linux. Источник требований — пользователь и исходный план, §7 и §25.
Этот этап устраняет структурные расхождения; точное совпадение ещё не достигнуто.

19 октября 2026, повторно просмотрены реальные развёрнутые окна обоих приложений.
Полученные изображения: 1707 × 1027. Скриншоты отображены в чате.
DPI не измерен, пиксельное сравнение не выполнялось.

| Поверхность | Выполнено | Осталось |
|---|---|---|
| Оболочка | Убрана крупная собственная toolbar с названием продукта | Quick Access в title bar, точные иконки и метрики |
| Меню | Наблюдаемый порядок, Home/PCB контекст, File, Ctrl+F4 | Полное содержимое и геометрия каждого меню |
| Projects | Левая область 330 points, toolbar, Search, дерево, нижняя вкладка | Точные иконки, строки, заголовок, pin/autohide; проектная модель |
| Messages/Properties | Одна правая область 316 points, нижние вкладки, реальное переключение | Полный docking, точные header/tab states, pin/float |
| Properties | Существующие реальные свойства и правки сохранены | Наблюдаемые General/Parameters/Health Check, Selection Filter, Snap Options |
| Active Bar | Компактная центральная полоса, доступные Fit/Grid/Select | Набор, размеры, пиктограммы, поведение всех инструментов |
| Цвета и плотность | Нейтральный серый shell/canvas, более плотные контролы | Цвета пока подобраны визуально; точные измерения, шрифты и все состояния |
| Linux | Тот же Rust UI и layout, X11/Wayland, CI | Реальный запуск, сопоставление шрифтов, DPI и ввода |

Проверены реальные переключения Messages → Properties. fmt, clippy и четыре
существующих теста проходят; новая сборка запущена и просмотрена.

Неподдерживаемые инженерные команды отключены. Их присутствие в меню не
означает реализации. Различия геометрии двух текущих плат не являются
результатом сравнения одинакового документа: native Altium import ещё отсутствует.

## Реализовано и проверено

В PCBCraft библиотека открывается через File → Open (Ctrl+O), либо Components →
меню → Install Library…. Панель доступна через View и Panels → Components,
а также Place → Part… → Components. Список установленных путей сохраняется
в настройках PCBCraft и читается при следующем запуске. Ссылки на существующие
SchLib/IntLib в PrjPcb загружаются при открытии проекта и доступны из его дерева.
Запись состава Altium-проекта не реализована.

Поиск сопоставляет слова с именем, описанием и параметрами; это локальный
поиск, без обращения в Workspace. Details показывает значения и описания ссылок.
Symbol даёт предпросмотр, номер части, режим отображения и Place. Model
показывает имена/типы связей моделей. Двойной щелчок по строке или Place
контекстного меню начинает повторное размещение на активной схеме.
Space поворачивает, щелчок вставляет, Esc/правая кнопка завершает.
Назначается свободный designator. Все вставки проходят проверку модели и историю.

Для проверки использована предоставленная ReferenceB.IntLib: 31 символ,
в том числе 7084 с четырьмя режимами отображения. Чтение выполняет Rust-код
через CFB/zlib. Altium не вызывается для импорта, preview или размещения.
SchLib Binary 5.0 читается напрямую; IntLib — через вложенные SchLib.
Нормализуются текстовые записи, бинарные выводы, PinFrac, PinTextData,
UTF-16 PinWideText, шрифты, параметры, ссылки моделей и image Storage.
Части/режимы превращаются в отдельные варианты геометрии. Преобразование
индексов владельцев не смешивает компонент с синтетическим листом.

Экземпляр содержит собственные UUID, параметры, геометрию, шрифты и изображения;
сохранённый .pcbcraft.json открывается без исходной библиотеки. Native-библиотеки
не перезаписываются. CLI для диагностики:
`cargo run -p eda-io --example library_inspect -- path/to/library.IntLib`.

## Границы текущего этапа

Это рабочий первый этап, а не полное визуальное и функциональное совпадение.
Остаются отличия стандартных элементов egui, шрифтов, иконок, рамок, разделителей,
звёзд избранного, изменения размеров колонок и соотношения таблица/Details.
Нет drag-and-drop из панели, управления удалением/обновлением библиотек,
редактора SchLib, обновления экземпляров из определения и упаковки многосекционных
компонентов в физические корпуса. Часть выбирается, но учёт пакетов/аннотация
многосекционных устройств ещё предстоит. Параметры определения через Components
не редактируются; редактирование размещённого экземпляра остаётся в Properties.

Нет ASCII SchLib, DbLib/SVNDbLib, managed Workspace, серверного поиска,
footprint/PCB geometry и 3D preview; соответствующие команды отключены.
Связь с моделью — метаданные, а не готовый footprint/simulation. Специальные
позиции надписей выводов и ширины символов выводов ещё не обеспечивают точную
визуальную совместимость. Неизвестные видимые записи дают предупреждения.
Поддержка всех разновидностей Altium-библиотек не заявляется.

Windows GUI проверен вручную: импорт, 31 строка, поиск LMV321, вставка 1396
как C7 на копии схемы, Escape, Undo/Redo, восстановление установленной библиотеки
после перезапуска. Linux GNU проверяется компиляцией всех targets; Linux GUI
и совпадение метрик на нём не проверены.

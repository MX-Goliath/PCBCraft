# Components и локальные библиотеки — наблюдения 20.10.2026

Эталон: запущенный Altium Designer Enterprise 24.4.1, окно 1707 × 1027
логических точек. Открыта ReferenceB.SchDoc. Пользователь отдельно поручил
начать Components, поэтому прежнее ожидание полного совпадения Properties
перестало блокировать этот этап. Точность Properties по-прежнему частичная.

- Верхняя строка: фильтр, выпадающий список библиотеки, меню, переключатель вида.
  В списке раздел FILE-BASED LIBRARIES, в том числе ReferenceB.IntLib.
- Поиск; таблица Design Item ID / Description / Value, строки около 18,

## Реализовано и проверено

В PCBCraft библиотека открывается через File → Open (Ctrl+O), либо Components →
меню → Libraries Preferences… → Install…. Панель доступна через View и Panels → Components,
а также Place → Part… → Components. Список установленных путей сохраняется
в настройках PCBCraft и читается при следующем запуске. Ссылки на существующие
SchLib/IntLib в PrjPcb загружаются при открытии проекта и доступны из его дерева.
Запись состава Altium-проекта не реализована.

Поиск сопоставляет слова с именем, описанием и параметрами; это локальный
поиск, без обращения в Workspace. Details показывает значения и описания ссылок.
Models даёт предпросмотр символа, сведения о footprint и ссылки моделей.
Часть и режим отображения выбираются в контекстном меню карточки.
Двойной щелчок по строке/карточке или Place контекстного меню начинает
повторное размещение на активной схеме.
Space поворачивает, щелчок вставляет, Esc/правая кнопка завершает.
Назначается свободный designator. Все вставки проходят проверку модели и историю.

Перетаскивание строки или белой карточки на свободный canvas вставляет один
компонент при отпускании левой кнопки. До отпускания меняется только preview.
Выход за canvas, Esc, потеря фокуса и переключение документа отменяют перенос.
Drop проверяет исходный UUID сеанса и ревизию; быстрый жест в одном кадре
также обрабатывается. Одна вставка — одна операция Undo/Redo. Жест работает
через egui и координаты eda-render, без Win32/OLE drag-and-drop.

Для проверки использована предоставленная ReferenceB.IntLib: 31 символ,
в том числе 7084 с четырьмя режимами отображения. Чтение выполняет Rust-код
через CFB/zlib. Altium не вызывается для импорта, preview или размещения.
SchLib Binary 5.0 читается напрямую; IntLib — через вложенные SchLib.
Нормализуются текстовые записи, бинарные выводы, PinFrac, PinTextData,
UTF-16 PinWideText, шрифты, параметры, ссылки моделей и image Storage.
Части/режимы превращаются в отдельные варианты геометрии. Преобразование
индексов владельцев не смешивает компонент с синтетическим листом.

Экземпляр содержит собственные UUID, параметры, геометрию, шрифты и изображения;
сохранённый .pcbcraft.json открывается без исходной библиотеки. Native-библиотеки
не перезаписываются. CLI для диагностики:
`cargo run -p eda-io --example library_inspect -- path/to/library.IntLib`.

## Границы текущего этапа

Итерация сверки 20.10.2026: при окне 1707 × 1027 и dock 316 воспроизведены
порядок верхних элементов, поиск со строкой активного фильтра, таблица с шагом
18, заголовок Details около y=559 и белая карточка 248 × 184 около y=773
для 1396 с пятью избранными параметрами. Колонки сортируются и меняют ширину;
разделитель таблица/Details перетаскивается. Свёрнутый Details остаётся над
вкладками. Expanded-параметры сортируются без учёта регистра/пунктуации;
звёзды меняют избранное, Show Less оставляет только избранные.

Наблюдено: 1396 показывает синие C? и 1005\\0402, серое исходное
`="C_USDD"`, а не вычисленное значение Comment. В 7086 (LMV321) видны
DA?, `="Part Number"` и стрелки электрических типов вход/выход.
Реализовано: отдельное преобразование presentation только для preview;
геометрия и значения размещаемого экземпляра не меняются. Масштаб карточки
подбирается по видимым bounds со шрифтами, скрытые параметры исключены.
Value в таблице — параметр Value; Comment не подставляется вместо него.
В предоставленной IntLib нет вложенного PcbLib: показано наблюдавшееся
«Footprint is not present». Для прочих контейнеров отсутствие preview
не объявляется отсутствием модели.

Полное пиксельное совпадение пока не подтверждено. Остаются различия
растеризации шрифтов, некоторых иконок/цветов, полос прокрутки и стандартных
egui controls. Другие масштабы/DPI, все символы/режимы, электрические маркеры
кроме наблюдённых input/output и native-диалог Libraries Preferences не сверены
полностью. Информационные тексты Workspace частично восстановлены по обрезанному
native виду; ссылки References/Manufacturer Part Search/Learn More отключены.
Неподдержанные фильтры, переключение вида и Refresh также не активируются.
Нет управления удалением/обновлением библиотек,
редактора SchLib, обновления экземпляров из определения и упаковки многосекционных
компонентов в физические корпуса. Часть выбирается, но учёт пакетов/аннотация
многосекционных устройств ещё предстоит. Параметры определения через Components
не редактируются; редактирование размещённого экземпляра остаётся в Properties.

Нет ASCII SchLib, DbLib/SVNDbLib, managed Workspace, серверного поиска,
footprint/PCB geometry и 3D preview; соответствующие команды отключены.
Связь с моделью — метаданные, а не готовый footprint/simulation. Специальные
позиции надписей выводов и ширины символов выводов ещё не обеспечивают точную
визуальную совместимость. Неизвестные видимые записи дают предупреждения.
Поддержка всех разновидностей Altium-библиотек не заявляется.

Windows GUI проверен вручную: импорт, 31 строка, поиск LMV321, вставка 1396
как C7 на копии схемы, Escape, Undo/Redo, восстановление установленной библиотеки
после перезапуска. Новая итерация: перенос из строки и карточки на собственной
схеме, C1/C2, Undo/Redo, сохранение/повторное открытие; визуальная сверка
1396 и 7086 с открытым Altium. Headless egui-тесты покрывают оба источника,
обычный/быстрый жест, preview без изменений модели, отмену, смену вкладки,
устаревшую ревизию и доступность свёрнутого заголовка. Всего 43 workspace tests.
Linux GNU проверяется компиляцией всех targets; Linux GUI и совпадение метрик
на нём не проверены. Исходные SchDoc/IntLib пользователя не перезаписывались.
